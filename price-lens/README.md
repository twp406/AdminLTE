# 价探 PriceLens

面向电商场景的商品价格自动化采集与横向对比工具：输入关键词，抓取京东 / 淘宝 / 拼多多的商品名称、价格、销量、店铺评分与链接，自动清洗去重、按价格排序、计算性价比，并输出终端报告与可交互的演示网页。

核心链路零第三方依赖（仅 Python 标准库），演示数据离线可复现。

## 快速开始

```bash
cd price-lens

# 1. 命令行采集（离线演示数据）
python cli.py search "无线蓝牙耳机"
python cli.py search "机械键盘" --sort value --format md --out report.md
python cli.py search "保温杯" --format csv --out data/result.csv

# 2. 启动演示网页（现场运行采集脚本）
python server.py --port 8000
# 浏览器打开 http://127.0.0.1:8000
```

环境要求：Python 3.10+（已在 3.14 验证）。

## 功能

- 三平台统一采集：京东、淘宝、拼多多，支持按关键词、平台、数据源筛选。
- 数据清洗：货币符号 / 千分位 / HTML 标签 / 中文销量单位归一化，缺失字段补全。
- 去重合并：同平台同标题指纹 + 价格接近的重复铺货自动合并。
- 异常识别：绝对值阈值 + 平台中位数倍数，剔除 0.01 元占位价、离谱高价。
- 横向对比：价格区间、中位数、均值、平台价差、店铺评分与月销对比。
- 性价比建模：价格、销量、评分归一化加权，输出推荐标注。
- 价格趋势：30 天平台均价与推荐单品曲线（自定义 SVG，交互悬浮）。
- 多格式报告：终端表格、JSON、CSV、Markdown。
- 演示网页：初始化自动展示示例结果，支持输入关键词现场运行、排序切换、趋势切换、CSV/MD 导出。

## 数据获取核心逻辑

统一适配器接口：

```python
class BaseAdapter:
    def search(self, keyword: str, limit: int = 40) -> list[dict]:
        ...
```

返回原始记录，允许脏字段，由清洗层统一处理。

### 演示数据源（默认）

`DemoAdapter` 使用 `blake2b(keyword)` 生成固定随机种子，确保同一关键词每次生成完全一致的数据。每条商品包含名称、价格、原价、销量、评分、店铺、URL，并刻意注入六类脏数据：

1. 价格带 `¥` 和千分位（如 `"¥1,299.00"`）；
2. 销量带中文单位（如 `"1.2万+"`）；
3. 标题带 HTML 标签与实体（如 `<em>...</em>`）；
4. 缺失价格 / 评分的记录；
5. 标题加营销后缀的重复铺货；
6. `0.01` 元占位价与 `88888` 元异常价。

### 实时数据源（需网络）

```bash
# 淘宝、拼多多搜索需要登录 Cookie
export TAOBAO_COOKIE="..."
export PDD_COOKIE="..."
python cli.py search "无线蓝牙耳机" --source live
```

- 京东：解析搜索页商品块，批量请求 `p.3.cn` 价格接口。
- 淘宝：解析 `g_page_config` 中的 `auctions` 列表。
- 拼多多：解析移动端页面 `window.rawData`，递归提取商品节点。

实时适配器是「最佳努力」实现：平台登录态、风控和页面结构变化都可能导致失败。失效时该平台记录告警并继续其他平台；全部失败时返回明确错误，建议切换演示数据源。采集频率应保持克制，仅用于学习研究，遵守目标平台 `robots.txt` 与服务条款。

## 清洗与去重规则

| 脏数据类型 | 处理方式 |
| --- | --- |
| `¥`、`￥`、千分位、中文单位 | 提取数值并归一化，`万` × 10000 |
| HTML 标签、实体、零宽字符 | 反转义、去标签、压缩空白、NFKC |
| 价格缺失 / 标题为空 | 计入无效记录并丢弃 |
| 同平台同标题重复铺货 | 标题指纹 + 价格偏差 ≤ 20% 时合并，保留销量更高者 |
| 价格 `< 5` 或 `> 50000` | 直接判为异常价 |
| 价格高于平台中位数 8 倍 | 稳健离群判定，剔除异常高价 |
| 店铺评分缺失 | 用同平台评分中位数补全，无数据时回退 4.6 |

演示关键词「无线蓝牙耳机」的实际链路：原始 51 条 → 字段有效 48 条 → 去重 6 条、异常价 3 条 → 最终 39 条，补全评分 3 条。

## 性价比模型

各维度先做归一化：

- 价格分：对数价格的反向归一化（越低越高）；
- 销量分：`log1p(sales)` 归一化（避免头部商品碾压）；
- 评分分：`(rating - 3.5) / 1.5` 截断到 0–100。

```text
value_score = 0.45 × price_score + 0.35 × sales_score + 0.20 × rating_score
```

推荐位去重后输出：性价比首选、全场最低、销量冠军 / 热销之选、口碑之选。商品标签还包括「高性价比」「低于均价」「热销」「口碑好」。

## 可视化方案

网页使用原生 SVG 绘制趋势图，不依赖 ECharts 或 CDN，断网也能完整展示：

- 平台均价：三条曲线按真实价格水平绘制，图例展示 30 天涨跌幅；
- 推荐单品：单条曲线 + 渐变面积，自动适配价格区间；
- 交互：鼠标悬浮显示日期、各平台价格、垂直参考线与高亮点；
- 响应式：按容器宽度动态计算 viewBox，窄屏自动压缩坐标轴字号与边距。

页面结构：

1. 搜索区：关键词、示例词、平台开关、排序、数据源、采集流水线状态；
2. KPI：最低价、价格中位数、有效商品数、清洗动作；
3. 性价比推荐：四个互不重复的推荐位；
4. 商品横向对比：价格 / 销量 / 评分 / 性价比 / 标签 / 外链，支持四种排序；
5. 平台对比：价格区间条 + 中位价标记；
6. 运行日志：逐步输出采集、清洗、去重、建模、图表耗时；
7. 价格趋势：平台均价 / 推荐单品切换；
8. 数据质量：51 → 48 → 39 → 39 漏斗，原始脏数据与清洗结果并排展示。

## CLI

```bash
python cli.py search "关键词" \
  [--source demo|live] \
  [--platforms jd,tb,pdd] \
  [--sort price|value|sales|rating] \
  [--limit 30] \
  [--format table|json|csv|md] \
  [--out path] \
  [--no-color]

python cli.py serve [--host 127.0.0.1] [--port 8000] [--source demo|live]
```

- `table`：宽字符对齐的终端表格，含推荐与平台对比；
- `json`：完整流水线结果，便于二次处理；
- `csv`：Excel 友好（写入文件时带 UTF-8 BOM）；
- `md`：可直接归档的比价报告。

## Web API

| 接口 | 说明 |
| --- | --- |
| `GET /api/search` | 参数 `keyword`、`platforms`、`source`、`sort`、`limit`，返回完整结果 |
| `GET /api/export` | 同上，另加 `format=csv\|md\|json`，作为附件下载 |
| `GET /api/health` | 健康检查 |

网页的「开始采集」会携带当前关键词调用 `/api/search`，服务端执行同一条 `run_pipeline` 流水线并返回结果与日志，因此页面展示的是现场运行结果，而非静态写死的数据。`web/sample-data.js` 仅作为直接打开 HTML 或接口不可用时的兜底示例。

## 限制与合规

- 演示数据为算法生成，价格与店铺均为虚构，仅用于展示工具能力，不构成购买建议。
- 淘宝 / 拼多多无公开搜索 API，实时采集依赖登录态并受风控限制；本项目不包含验证码破解或登录绕过。
- 实时采集请遵守目标平台服务条款与 `robots.txt`，控制请求频率，仅用于学习研究。
- 生产化建议：接入官方开放平台 API、代理池与限速器、SQLite/MySQL 快照存储、定时任务（每日价格快照）、告警与监控；趋势模块可直接消费按日快照累积真实曲线。

```python
class XxxAdapter(BaseAdapter):
    code = "xxx"
    name = "某平台"

    def search(self, keyword: str, limit: int = 40) -> list[dict]:
        return [...]  # 允许脏字段
```

然后在 `engine.LIVE_ADAPTERS` 与 `PLATFORM_NAMES` 中注册，即可复用清洗、评分、趋势、报告与网页的全部能力。
